# MovieHub
This is a React Movie Search App that allows users to discover and manage their favorite movies. Built with modern React features including hooks, context API, and local storage for data persistence.

Key Features:

🔍 Movie Search - Search movies using OMDB API with debounced input

❤️ Favorites System - Add/remove movies with animated heart button

💾 Local Storage - Favorites persist between sessions

📱 Responsive Design - Works on desktop and mobile

⚡ Real-time Updates - Instant search results and favorite status

Tech Stack:

React 18 with Hooks (useState, useEffect, useContext)

React Router for navigation

Context API for state management

OMDB API for movie data

CSS3 with animations and responsive design

Local Storage for data persistence

Architecture:

Component-based architecture

Custom hooks for movie context

Debounced search for performance

Error handling and loading states

This project demonstrates modern React development practices including state management, API integration, and user experience optimization."
